Errors now show on screen.

Every database and storage call shows its error at the bottom of the screen,
with the action that failed (for example 'Load posts: ...').

Apply in Termux:
  unzip -o ~/storage/downloads/swifs_show_errors.zip -d ~/NewApp
  cd ~/NewApp && git add -A && git commit -m 'Show errors on screen' && git push

No SQL to run for this change.
