Native (phone) alerts for the new list notifications
====================================================

Every new row in the notifications table already starts a push through the
push-notify Edge Function. The new list types are sent with the generic text
"New Activity" until you add these cases. Open the function in Supabase
Dashboard -> Edge Functions -> push-notify, find the describe() switch (it
starts with: function describe(kind: string, who: string)), and add these
lines just above the line:    default: return { title: "New Activity", ...

    case "list_add": return { title: "Added to a List", body: `${who} added you to a list` };
    case "list_join": return { title: "New Member", body: `${who} joined your list` };
    case "list_request": return { title: "Join Request", body: `${who} asked to join your list` };
    case "list_request_accepted": return { title: "Request Accepted", body: `${who} accepted your request to join a list` };
    case "list_post": return { title: "New List Post", body: `${who} posted in a list you are on` };

Nothing else changes: the list types only need the push_notifications switch
(the KIND_SWITCH table does not list them), so people who turned off
notifications get no list pushes.
